## 3. Личные впечатления и визуальное качество (User Observation)

> [!WARNING]
> **Качество вывода (Aliasing vs Smooth):**
> При использовании одной и той же нейросетевой модели:
> * **TensorRT:** выдал заметный **Aliasing (лесенка / ступенчатость / зубчатость контуров и резких границ)** на апскейленом видеоряде.
> * **PyTorch:** выдал чистую, цельную и **гладкую (smooth)** картинку без ступенчатых артефактов квантования / интерполяции.

### Возможные технические причины алиасинга в TRT:
1. **Режим квантования FP16 и внутренние слияния слоев (Fusion):** TensorRT 11.4 оптимизирует свертки и слои интерполяции (Resize / Nearest / Bilinear / Bicubic), агрессивно объединяя их с активациями. В FP16 накопление ошибок в дельта-весах и координатных сетках (grid sampling) может вызывать сдвиг субпиксельных координат и резкие границы.
2. **Алгоритм Resize / Interpolation в TensorRT:** При экспорте `align_corners` или `half_pixel` режимов через ONNX в TRT плагин `Resize` может интерполировать координаты иначе, чем нативный ATen-ядро PyTorch (`torch.nn.functional.interpolate`).
3. **Отсутствие FP32 Fallback для чувствительных слоев:** При сборке TRT FP16 без явного `obey_precision_constraints` или смешанной точности (Mixed Precision FP16/FP32 для блоков ресемплинга) точность координат теряется сильнее.
